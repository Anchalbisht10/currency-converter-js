# Currency Converter
---
## Description
A currency converter application that converts values between different currencies using real-time exchange rates.
---
## Tech Stack
- JavaScript
- HTML
- CSS
- API Integration
---
## Features
- Convert currency values instantly
- Display country flags dynamically
- User-friendly interface
- Real-time exchange rates
---
## How to Run
1. Open the project folder
2. Run using Live Server or open `index.html`
